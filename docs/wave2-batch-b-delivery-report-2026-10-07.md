11. **Item transfers/adjustments:** Actual matching lines / single-item adjustment rows, dates, From/To, state, delta/reason. Existing document actions remain separate; no stock mutation in Item View.

13. **Warehouse sections:** Overview; Stock On Hand; Ledger; Goods Receipts; Material Issues; Transfers; Adjustments; Project/Site Context; Activity. Persistent code/name/status/context and permitted stock summaries; shared Save & stay/Close/New/Cancel and Back behavior.

15. **Warehouse valuation:** Stored per-warehouse average cost / total value. Summary sums the same authorized set. No new formula, FIFO engine, or master stock editor.
16. **Warehouse GRNs:** Lines of receipts whose direct `warehouse_id` is the URL parent; unrelated receipts hidden. Existing receipt/PO/supplier/Project/Site context and F04 quantities require their respective permissions.
17. **Warehouse issues:** Posted issue lines whose warehouse is the parent, labelled by item/unit, quantity and permitted value/context. Existing Issue View remains the destination.
18. **Warehouse transfers:** Both authorized inbound/outbound directions selected through From/To; unrelated transfers excluded. Existing global scope retained: Project/Site is source-only; warehouse scope is either endpoint. Hidden counterpart label is replaced by Outside permitted scope. Standard seeded roles still lack Receive; no permission grant was added.
19. **Warehouse adjustments:** Exact parent's existing single-item adjustments, quantity change/reason/state and gated value. No inline stock edits or approval/post actions.
20. **Project/Site links:** Scoped existing relations with independent Projects/Sites view gates and safe return to the Warehouse context. No duplicate workspaces. Existing Warehouse Project/Site cannot be changed through profile save; new Site must match visible Project.
21. **Permissions:** Parent Items/Warehouses view plus the actual child module permission at direct endpoints. Warehouse Stock view gates all new monetary inventory columns and summaries. Chart of Accounts view gates Item account mappings; AP view gates F04 quantities; Activity Logs view gates activity. No automatic role grants.
22. **Scope:** Existing global scopes retained. Item stock/history additionally intersects authorized warehouses; Warehouse panels use the exact authorized route parent. Hidden records are neither listed nor added to totals. Existing source-only Project/Site transfer and ledger attribution limitations are documented, not bypassed.

History-only unscoped existence checks prevent deletion without disclosing hidden rows.

# ZATCA Phase 2 — official source baseline (reviewed 17 October 2026)

This record ties every compliance decision in the Seera ZATCA implementation (sprint 1: compliant XML, cryptographic stamp, sandbox clearance and reporting) to the official ZATCA material consulted on 17 October 2026. Third-party articles, forums and libraries were **not** used as authority. When ZATCA publishes a new version of any document below, re-check the decisions table before changing code.

## Reproducible SDK setup (prepared 17 Oct 2026; SDK NOT RUN — download is login-gated)

1. Runtime: Temurin OpenJDK 11.0.25+9 (`OpenJDK11U-jdk_x64_windows_hotspot_11.0.25_9.zip`, 199,993,997 bytes, from `https://github.com/adoptium/temurin11-binaries/releases/download/jdk-11.0.25%2B9/`). Unzip to a tools folder outside the repository; `jdk-11.0.25+9\bin\java.exe -version` must print `11.0.25`. The SDK manual (#10) requires JDK ≥ 11 and < 15 for secp256k1; PhpStorm's bundled JBR 17 is not acceptable.
2. SDK: sign in to the Developer Portal (`https://sandbox.zatca.gov.sa/`, owner's account), open "Compliance and Enablement Toolbox SDK", accept the terms, download the JAR build; or use the "Download SDK" link on the ZATCA website (both land on the login-gated SharePoint). Unzip into its own empty folder; do not commit it. Record the version shown by `fatoorah -v` (manual CLI name; the shipped wrapper may be `fatoora`).
3. Inputs: export from Seera (FIN-ZAT-002 → XML downloads) the unsigned and signed XML of a standard and a simplified document, plus the compliance-check documents if needed.
4. Commands per #10 §3.2.4: `fatoorah validatexml -f <signed.xml>` (rule results), `fatoorah validatexml -f <new.xml> -p <previous.xml>` (PIH), `fatoorah validateqr -qr <base64>` (QR tags), `fatoorah generatehash -f <unsigned.xml>` (compare with `invoice_hash` on the record, D-07), `fatoorah generate -f <unsigned.xml> -x` (SDK signature for comparison, D-10). Record PASS / WARNING / ERROR with rule ids in the evidence document; secrets never appear in the outputs.
5. Sandbox onboarding with Seera's CSR is already proven (evidence doc); successful toolbox or sandbox results are development evidence only. Production onboarding is an owner step in the FATOORA portal with the company's own OTP.

# Figma Designer Brief - Phase 5 Projects + Site Expenses

Goal: Design the Projects and Site Expenses module for a Saudi construction ERP.

This phase should use the same admin design system from Phase 1 to Phase 4:
- Dark sidebar
- White cards
- Blue primary buttons
- Filter bars
- Status badges
- Grouped form sections
- Tables with clear actions
- Approval trails
- Accounting posting indicators

Screens:
1. Project Dashboard
2. Projects Listing
3. Add/Edit Project
4. Project Details
5. Project Budget / BOQ
6. Project Milestones
7. Project Cost Tracking
8. Site Expenses Listing
9. Add Site Expense
10. Expense Details
11. Expense Approvals
12. Expense Payments / Settlements
13. Daily Site Reports
14. Accounting Posting Preview
15. Project Reports

Important UX Notes:
- Site expense form must be simple enough for supervisors.
- Invoice photo upload should be prominent.
- Approval status should clearly show current step: PM pending, Finance pending, Approved, Rejected.
- Accounting posting status should show Posted / Ready / Failed.
- Project budget should show estimated, committed, actual, and variance.
- Daily site reports should show manpower, work progress, issues, photos, and status.

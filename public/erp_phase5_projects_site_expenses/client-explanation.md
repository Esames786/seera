# Client Explanation - Phase 5 Projects + Site Expenses

Phase 5 will build the project execution and site expense management layer of the ERP.

This phase includes:
- Project dashboard
- Project budget and BOQ tracking
- Project milestones
- Project cost tracking
- Site expense entry
- Invoice photo upload
- Expense approvals
- Expense payments and settlements
- Daily site reports
- Accounting posting preview

Why this phase is important:
Site teams can submit expenses against a project and site. Project managers can approve or reject them. Finance can approve payment and post approved expenses into accounting.

Example workflow:
1. Site Supervisor enters fuel/material expense with invoice photo.
2. Project Manager checks project/site/category and approves.
3. Finance verifies amount/VAT/payment method and approves.
4. System creates accounting posting:
   - Debit Expense Account
   - Debit Input VAT
   - Credit Cash/Bank/Petty Cash/AP
5. Project cost report updates automatically.

seera.test/admin/roles/create rendered from commit 17aeba0
What changed on this screen
  • Role Type (Manager, Assistant, Supervisor, In-Charge, …) plus Department fills a consistent name and code: Purchase + Assistant becomes "Purchase Assistant" / PURCHASE_ASSISTANT. Code is generated from the name when left blank.
  • All column first in the matrix; ticking it grants the row, then any single action can be unticked. Partly ticked rows show a half-filled box.
  • Choosing a department narrows the matrix to that department's modules. Show all modules brings everything back. Hidden modules keep whatever they had.
  • Select all visible / Clear visible act on the rows currently shown.
  • Actions this compact matrix does not show (Post, Process, Receive, Issue, Transfer, Adjust) are no longer revoked when the form is saved.
Try it in the frame

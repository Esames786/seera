# Figma Designer Brief - Phase 4 Accounting + VAT + ZATCA

Goal: Design the finance module using the same visual style from earlier phases.

Screens:
1. Accounting Dashboard
2. Chart of Accounts
3. Journal Entries
4. General Ledger
5. Accounts Payable
6. Accounts Receivable
7. VAT Management
8. ZATCA E-Invoicing
9. Financial Reports
10. Project-Based Cost Centers
11. Automatic Posting Rules

Important UX:
- Finance dashboard should show cash/bank, AP, AR, VAT payable, unposted journals, ZATCA failures.
- Chart of Accounts should show a clear tree structure.
- Journal Entries should have header + line items.
- VAT screen should separate output VAT, input VAT, and payable.
- ZATCA screen should show XML, QR, UUID, clearance status, failed retry.
- Reports should include Balance Sheet, Profit & Loss, Trial Balance, Cash Flow.
- Posting rules should show how payroll, expenses, inventory, and invoices auto-create journal entries.
